# Portfolio

A one-page portfolio built with React, Vite, and Tailwind CSS.

## Getting started

```sh
npm install
npm run dev
```

Edit `src/data/portfolio.js` to add your education, experience, projects, skills, contact information, and links. Empty social links appear as “coming soon” until URLs are supplied. Resume can be a URL or a file placed in `public` (for example, `/resume.pdf`). The section layout lives in `src/App.jsx`, and reusable UI components are in `src/components`.

Tailwind utilities live alongside the components. The Vite configuration provides the Tailwind stylesheet entry.
